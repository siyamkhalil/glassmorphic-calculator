# 📱 Glassmorphic Responsive Calculator

A sleek, modern, and fully functional digital calculator featuring a beautiful glassmorphic dark-theme user interface. Built from scratch using semantic HTML5, modern CSS Grid/Flexbox layouts, and clean Vanilla JavaScript mathematical evaluation logic.

---

## ✨ Features

- **Fluid Responsiveness:** Works perfectly across ultra-wide desktop monitors, tablets, and small mobile viewports.
- **Glassmorphism UI:** Features a high-tech translucent background layer with neon accent colors.
- **Robust Math Logic:** Handles additions, subtractions, multiplications, and divisions while accurately resolving floating-point decimal approximations.
- **Error Filtering:** Safe-guards against operations like dividing numbers by zero (`Error` prompt handling).
- **Interactive Controls:** Includes utility operations like a universal clear (`C`) screen switch and a single-character backspace delete key.

---

## 🛠️ Tech Stack Used

| Layer | Technology |
| :--- | :--- |
| **Structure** | HTML5 (Semantic Elements) |
| **Styling** | CSS3 (Grid System, Flexbox, Media Queries, Backdrop-Filters) |
| **Logic** | Vanilla JavaScript (ES6+ Architecture) |
